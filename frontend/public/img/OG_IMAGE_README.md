# Open Graph Image for Zenith 2026

## Required Image Specifications

Create an image with the following specifications for optimal social media sharing:

### Dimensions
- **Recommended Size**: 1200 x 630 pixels (1.91:1 aspect ratio)
- **Minimum Size**: 600 x 315 pixels
- **Maximum File Size**: 8MB

### Content Suggestions
1. Zenith 2026 logo prominently displayed
2. "SGGS Sports Fest" text
3. Sports imagery (stadium, players, sports equipment)
4. Dates: February 1-5, 2026
5. Tagline: "The Ultimate Sports Experience"

### Design Guidelines
- Use high contrast for readability
- Include the purple/violet theme color (#7c3aed)
- Add event dates clearly visible
- Keep text minimal but impactful

### File Location
Save the final image as:
- `/frontend/public/img/zenith-og-image.jpg`

### Tools to Create
- Canva (free): https://www.canva.com
- Figma: https://www.figma.com
- Adobe Express: https://www.adobe.com/express
